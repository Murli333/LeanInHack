## 🎯 Design Objectives

1. **Accessibility First:** Clean, high-contrast visual cues accessible across different literacy levels and age groups (elderly citizens vulnerable to digital arrest and pension scams).
2. **Immediate Clarity:** Clear 3-tier verdict cards (`Safe`, `Suspicious`, `Scam`) with 0–100% animated risk gauge meter.
3. **Dual Form-Factor:** Seamlessly functions as both a standalone mobile app (PWA / React Native / Flutter ready) and a responsive desktop web console.
4. **Actionable Remediation:** Never leaves the user with just a score; immediately provides next-step actions (e.g., "Report to 1930 Cyber Helpline", "Block number", "Do not share OTP").
