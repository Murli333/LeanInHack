# 🖼️ Design Assets

This directory contains visual assets, icons, and SVG component templates for the ScamLens user interface.

## Asset Inventory
- `verdict-safe.svg`: Green shield with checkmark badge.
- `verdict-warning.svg`: Amber triangle exclamation icon.
- `verdict-danger.svg`: Crimson hexagon danger alert icon.
- `gauge-meter.svg`: Circular progress gauge template with graduated tick marks.
- `mobile-frame.svg`: High-fidelity smartphone mockup bezel for desktop simulation view.
